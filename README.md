# Arrhythmia Recognition and Emergency Management

Skills Station SSC4, RESCUE KIDS 2026 (PSPEM 3rd Annual Scientific Convention),
Day 1, The Manila Hotel.

Jon Bryan S. Tiosin, MD — Division of Pediatric Emergency Medicine,
UP-Philippine General Hospital.

## What this is

A ten-slide teaching deck for a 25-minute hands-on skills station, delivered as
a single self-contained HTML file. No build step, no dependencies, no network
access required: every image is inlined, so `index.html` opens correctly from a
USB stick, an email attachment, or a web server.

The three algorithm charts are click-to-zoom. Click a chart to open it
full-screen, then scroll to zoom, drag to move, and use the toolbar for Fit or a
true 100 percent view. Escape closes it.

## Navigating

| Key | Action |
|---|---|
| Left / Right arrow, Page Up / Page Down, Space | Move between slides |
| Home / End | First / last slide |
| `F` | Fullscreen |
| Click a chart | Open the zoom viewer |
| Scroll / drag, `+` `-` `0`, Esc | Zoom, pan, reset, close |

The dots along the bottom are clickable.

edit the model and rebuild rather than hand-editing `index.html`, which is
